# Archived Astro compatibility layer

These files preserve the former Astro-to-Next.js compatibility implementation
for repository history. They are not loaded, compiled, generated, or executed
by the website.

The active website is implemented with native Next.js App Router routes and
React components. Do not restore the importer, generated markup,
`dangerouslySetInnerHTML` renderer, compiled scripts, or scoped Astro CSS to
active application code.

The archived files are retained instead of permanently deleted in accordance
with the repository deletion-safety policy.
