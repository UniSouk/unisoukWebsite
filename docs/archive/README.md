# Archived native styles

These styles are retained as recoverable migration references under the
repository deletion policy. The active native site shell uses Tailwind CSS v4.
The native blog index was migrated to Tailwind at the same time and its former
CSS Module is retained here for comparison.
The blog article route (`app/blogs/[slug]`) also uses Tailwind; its former route
module is retained here. The rich-text renderer remains a separate component
boundary and now also uses Tailwind utilities. Its former module is retained
here, together with the personalized demo module.
